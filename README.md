# Anemia Tracker

A school health management application designed to simplify anemia screening and monitoring among students.

## Overview

Anemia Tracker helps schools manage student health records, monitor hemoglobin (Hb) levels, track screening progress, and organize school health activities through dedicated dashboards.

## Features

- School administration dashboard
- Student and teacher management
- Hemoglobin record tracking
- Anemia screening progress monitoring
- Parent OTP verification
- Role-based authentication

## Tech Stack

- React Native
- Expo
- JavaScript
- Node.js
- Express.js
- PostgreSQL
- JWT Authentication

## Getting Started

### Frontend

```bash
cd anemia-tracker
npm install
npx expo start
```

### Backend

```bash
cd anemia-tracker-api
npm install
```

Configure the required environment variables before starting the backend.
